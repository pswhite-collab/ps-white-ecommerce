# PS White E-Commerce Website - User Guide

## For Customers

### Create an Account
1. Open `/register`
2. Register with email/password or use Google sign-in
3. Verify your email if required
4. Login at `/login`

### Buy a Book
1. Open `/books`
2. Filter/search titles
3. Open a book detail page
4. Choose format (eBook, physical, audiobook)
5. Add to cart
6. Checkout and complete payment
7. After successful payment, digital books appear in My Library

### Read eBooks
1. Open `/library`
2. Click `Start Reading` or `Continue Reading`
3. Use reader controls for page navigation
4. Change theme/font from settings
5. Add bookmarks with optional notes
6. Progress saves automatically

### Account and Orders
- View profile with `/auth/me` powered account data
- View order history and order details
- Download digital files from library/order area

## For Admin

### Admin Login
1. Open `/admin/login`
2. Use Google sign-in
3. Only whitelisted email (`pswhite786@gmail.com`) is allowed

### Manage Content
- Add/edit/archive books from Admin > Manage Books
- Upload cover, EPUB/PDF, and audio files
- Review orders and update status
- Moderate reviews and blog posts
- Monitor subscribers and reading analytics
