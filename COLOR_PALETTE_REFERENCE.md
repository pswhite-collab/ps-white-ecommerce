# PS White E-Commerce Website
## Color Palette Reference Guide
### Updated: March 22, 2026

## Primary Palette
- `#FBF7F4` Milk: main backgrounds and cards
- `#E5DED2` Oat: section backgrounds and input fields
- `#A39382` Taupe: borders, icons, accents
- `#685D54` Mocha: buttons, headings, active states
- `#232323` Charcoal: primary text, footer

## Semantic Tokens
- Backgrounds:
  - `--bg-primary: var(--milk)`
  - `--bg-secondary: var(--oat)`
  - `--bg-tertiary: rgba(163, 147, 130, 0.1)`
- Text:
  - `--text-primary: var(--charcoal)`
  - `--text-secondary: var(--mocha)`
  - `--text-tertiary: var(--taupe)`
  - `--text-inverse: var(--milk)`
- Borders:
  - `--border-default: var(--taupe)`
  - `--border-light: rgba(163, 147, 130, 0.3)`
  - `--border-strong: var(--mocha)`

## Interactive Colors
- Primary button:
  - base `#685D54`
  - hover `#5A4F47`
- Secondary button:
  - base `#A39382`
  - hover `#8F826F`
- Outline button:
  - border/text `#685D54`
  - hover bg `#685D54`, hover text `#FBF7F4`

## Status Colors
- Success: `#4A7856`
- Warning: `#B8864A`
- Error: `#B85450`
- Info: `#6B7A8F`

## Shadows
- Light: `0 2px 8px rgba(35, 35, 35, 0.08)`
- Medium: `0 4px 20px rgba(35, 35, 35, 0.12)`
- Strong: `0 16px 40px rgba(35, 35, 35, 0.26)`

## Reader Themes
- Light:
  - background `#FBF7F4`
  - text `#232323`
- Dark:
  - background `#232323`
  - text `#FBF7F4`
- Sepia:
  - background `#E5DED2`
  - text `#685D54`

## WCAG Notes
- Use `#232323` for body text on light backgrounds.
- Use `#685D54` for headings and larger text.
- Use `#A39382` for borders, icons, or large text only.
- On dark surfaces, use `#FBF7F4` for text.
